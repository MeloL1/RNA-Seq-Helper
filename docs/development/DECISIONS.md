# 开发决策

## D-0001：阶段 0 使用 Rscript JSON Lines 隔离边界

日期：2026-09-13

选择一次请求一个独立 `Rscript --vanilla` 进程，以先验证 R 方法、参数和 Python/R 契约，并将 R 状态或崩溃限制在单个任务内。规划中的 rpy2 集成保留到固定 ABI、standalone 运行时和 QThread 取消经过实际验证后；不因缺少 rpy2 阻断阶段 0 的分析基准。

## D-0002：阶段 0 不自动降级统计方法

日期：2026-09-13

`micro_deseq2` 在 DESeq2 不可用时直接返回错误；客户端不会改用 limma。这样保持“失败不得静默换方法”的产品约束，避免把运行时缺包伪装成分析结果。

## D-0003：参考映射只增强展示，不改变统计行

日期：2026-09-13

本地 GPL/SOFT/annot 或用户参考表只对原始特征编号做名称映射；一对多关系以分号列表保留，不能复制表达矩阵行或制造多个统计检验。参考不可用时继续保留原编号分析，并将状态、覆盖率、歧义数、未映射数、来源和 checksum 写入项目 `references/` 与报告清单。

## D-0004：GEO 元数据随整理结果离线保存

日期：2026-09-13

GEO Series Matrix 的 accession、title 和单一平台 ID 在生成 `sample_metadata.tsv` 与 `project.json` 时一并保存；不联网补齐样本含义，也不把 GSM 编号本身当作分组事实。多平台文件继续阻断混合整理。
